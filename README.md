# 🌸 此刻 FocusNow

> 专为拖延症和忙碌人群设计的日程管理软件（Windows / Android）

**当前版本：v1.5.0** | 纯本地运行 · 无需联网 · 数据不外传 · 零权限

---

## ✨ 核心功能

| 模块 | 功能说明 |
|------|---------|
| 📝 **专注待办** | 优先级分类、截止日期、分类标签（工作/学习/生活/健康/设计/绘制/其他）、预估时长、关联专注计时 |
| 🔔 **提醒日程** | 系统通知提醒、准时/提前 5~60 分钟、重复日程（每天/每周/每月） |
| 📅 **日程计划** | 日视图时间轴（6:00-23:00）、3 种拖拽模式（吸附/自由/定时）、当前时间红线 |
| 📊 **日历热力图** | 月历网格、专注热力着色（5 级）、分类筛选、点击查详情、月度统计 |
| ⏱ **专注计时** | 番茄钟（25/5/15 可配）、自定义计时、秒表、进度圆环、完成音效 |
| 🌟 **每日打卡** | 每日重复任务打卡、连续天数统计、自定义图标 |
| 📋 **今日安排台** | 未截止事项汇总、一键安排到今天、待办×日程双向绑定 |
| 🖱 **悬浮专注钟** | 桌面悬浮小组件、可拖拽移动、S/M/L 调大小、最小化小球 |
| 🎨 **皮肤系统** | 5 套主题（粉黑/Candy Pop/Midnight/Matcha/Strawberry）、CSS 变量热切换 |

## 🖥️ 运行方式

### Windows
安装 `release/FocusNow-Setup-1.5.0.exe`，双击桌面图标启动。
窗口按钮：`─` 最小化 · `□` 最大化 · `✕` 关闭挂后台（计时继续）· `⏻` 完全退出

### Android（7.0+）
安装 `release/FocusNow-1.5.0.apk`，沉浸式全屏、零权限。
右上角浮动 `✕` 挂后台 / `⏻` 完全退出，返回键 = 挂后台。

### 开发模式
```bash
cd focusnow
npm install
npx electron .
```

## 📝 自行更新

1. 用记事本或 VS Code 打开对应文件修改
2. `index.html` → 页面结构
3. `style.css` → 颜色/主题（`:root` 变量）
4. `app.js` → 功能逻辑
5. 保存后重新打开软件即生效

> 数据存在浏览器 localStorage 中，改代码不会丢数据。
